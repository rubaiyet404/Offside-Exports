🤖 Invoice Assistant Rule-based · not AI

This assistant understands simple patterns using built-in rules; it is not connected to any AI service.
How to connect a real AI Never put an API key in this file (anyone can read it). Create a small server (e.g. Node, Cloudflare Worker, Firebase Function) that keeps the key secret, calls an AI API, and returns JSON like {name, phone, address, items:[{name,size,qty,price}], paid, method}. Then replace the body of runAssistant() with: 
const r = await fetch('https://YOUR-SERVER/api/invoice-assistant', {
  method:'POST', headers:{'Content-Type':'application/json'},
  body: JSON.stringify({text}) });
applyParsed(await r.json());
